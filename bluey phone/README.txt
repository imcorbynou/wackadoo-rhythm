Bluey 手机照片同步

已实现
• bluey phone 手机网页：原素材、适配不同屏幕尺寸。
• 游戏结算页：Play again / Back to home / Save photo 三个按钮等间距居中。
• Save photo 悬停变为原设定蓝底白字，二维码卡片淡入；键盘聚焦同样生效。点击可在电脑下载照片，并保持二维码显示；Escape 可取消固定显示。
• 照片包含实际摄像头画面、相框、Bluey 和 Bingo，手机同步显示并可保存。
• 照片仅保存在服务内存中，刷新电脑游戏、重新开始、返回首页或退出页面时清除；15 分钟后自动过期。手机页面会在约 1.5 秒内更新或清空。已下载到手机的照片不会被删除。
• 摄像头未开启时不上传灰色占位图，手机等待下一张真实照片。

使用步骤
1. 保持桌面文件夹 bluey homepage、Bluey Vest Connect、Bluey Keepy Uppy Game、bluey phone 在同一目录。
2. 如果首页原来已经运行，请先在旧终端窗口按 Control-C 停止，再双击 bluey homepage/打开主页.command。不要同时运行旧版 Python 游戏服务器。
   也可以双击 Bluey Keepy Uppy Game/打开游戏（含手机照片）.command。
3. 电脑游戏用 http://127.0.0.1:8940/ 打开，开启摄像头并完成游戏。
4. 手机和电脑连接同一 Wi-Fi。手机页面固定地址：
   http://oujielangdeMacBook-Pro.local:8940/phone/
5. 在你制作二维码的平台中，把 https://qr.codes/AhfDaQ 的跳转目标修改成上面这条手机页面地址。二维码原图片无需替换，也没有改动它的任何像素。
6. 手机扫码后显示本局照片，点击 Save photo。支持系统分享的浏览器会打开分享面板；其他浏览器下载 PNG，如果打开了图片可长按保存。

连接条件
• 电脑要保持开机，服务终端保持运行。
• 手机和电脑同一 Wi-Fi；访客网络的设备隔离或系统防火墙可能阻止访问。如系统询问是否允许 Node.js 接受传入连接，请允许用于本次局域网访问。
• .local 地址不依赖 DHCP 分配的数字 IP，但更改这台 Mac 的本地主机名会改变地址。
• 为保证二维码稳定，端口固定为 8940。若提示占用，请先停止旧 Bluey 服务再启动，不会静默改到其他端口。
• 此地址是局域网地址，不是公共互联网网址。

GitHub 与今后上线
当前是可运行的局域网版本，没有上传 GitHub 或部署公共照片服务。手机静态页面可以发布到 GitHub Pages，但 GitHub Pages 不能运行这里的 Node.js 照片接口。
今后公开上线时，需要把照片服务部署为 HTTPS 后端，并接入电脑端上传授权和手机页读取地址，再把二维码平台的目标改为最终公开手机页地址；这张二维码图片仍然不必重做。
请不要把拍摄照片或游戏的 Python 虚拟环境上传到 GitHub。当前实现不会把照片写进这些文件夹。
